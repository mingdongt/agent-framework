# af-watch

Weekly expert-grade OSS contribution briefing across the agent framework ecosystem.

See `docs/superpowers/specs/2026-05-17-af-watch-design.md` for design.

## Quick start

```bash
cd python/tools/af_watch
uv venv && uv pip install -e ".[dev]"
af-watch init
af-watch run
af-watch open
```
